# HR Analytics Dashboard

## Project Overview
This project focuses on analyzing employee data to understand employee attrition and workforce trends using Power BI.

## Dataset
IBM HR Analytics Employee Attrition & Performance Dataset.

## Tools Used
- Microsoft Power BI
- Microsoft Excel

## Key Performance Indicators (KPIs)
- Total Employees
- Total Attrition
- Attrition Rate
- Average Employee Age
- Average Monthly Income

## Key Analysis
- Department-wise Employee Attrition
- Gender-wise Employee Analysis
- Age Group Analysis
- Job Role-wise Attrition
- Education Field Analysis
- Job Satisfaction Analysis

## Project Objective
To analyze employee data, identify attrition patterns, and generate meaningful insights that can help HR departments make better decisions.
